 Project Theme & Description
FlavorForge is an interactive digital recipe book web application designed to transform traditional messy paper cookbooks into an intuitive, responsive digital workspace. Home cooks can easily search, filter by cooking time/category/difficulty, view detailed step-by-step cooking instructions, and send direct messages via a real-time validated contact form.



 Technology Stack
- Frontend Structure:** HTML5, CSS3, Bootstrap 5 (CDN)
- Client-Side Logic:** Vanilla JavaScript (ES6+)
- Responsive Design:** Custom Breakpoints (Mobile, Tablet, Desktop)
- Version Control:** Git & GitHub
